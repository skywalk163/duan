# v4.0 → v5.x 迁移指南

## 概述

v5.x 在 v4.0 的基础上引入了类型系统（v4.3）、模块系统增强和性能优化。

## 新特性

### 1. 类型标注

```python
# v4.0 风格
段 加法(a, b):
  返回 a + b

# v5.x 风格（推荐）
段 加法(a: 数, b: 数) -> 数:
  返回 a + b
```

### 2. 泛型支持

```python
段 首元素[T](列表: 列[T]) -> T:
  返回 列表[0]
```

### 3. 联合类型

```python
段 处理(值: 数 | 串):
  若 值 是 数：
    印("数字")
  否则：
    印("字符串")
```

## 兼容性

- v5.x 完全兼容 v4.0 代码
- 类型标注是可选的
- 旧代码无需修改即可运行
