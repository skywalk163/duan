## 1. 环境准备

### 1.1 安装 Python

段言运行在 Python 之上，所以第一步是安装 Python（3.10 或更高版本）。

去 [python.org](https://www.python.org/downloads/) 下载安装包，运行时勾选 **Add Python to PATH**，一路「下一步」即可。

安装完成后，打开终端（Windows 按 `Win+R`，输入 `cmd` 回车），输入：

```bash
python --version
```

看到类似 `Python 3.12.x` 的输出就说明安装成功。

### 1.2 安装段言

在终端中执行：

```bash
pip install duan
```

### 1.3 验证安装

```bash
duan --version
```

看到 `段言编译器 v1.x.x` 说明安装成功。

现在创建一个测试文件 `hello.duan`，写入以下内容：

```段言
打印 "你好，段言！"
```

然后运行：

```bash
duan run hello.duan
```

如果终端输出 `你好，段言！`，恭喜你——环境搭建完毕！

### 小结

| 命令 | 作用 |
|------|------|
| `pip install duan` | 安装段言 |
| `duan --version` | 查看版本 |
| `duan run 文件名.duan` | 运行段言程序 |

## 2. 第一个程序

### 2.1 打印

`打印` 是段言最常用的命令，作用是把内容显示到屏幕上：

```段言
打印 "你好，世界！"
```

你也可以用括号写法，效果一样：

```段言
打印("你好，世界！")
```

### 2.2 变量

变量就像一个「盒子」，可以存放数据。用 `设` 来声明变量：

```段言
设 名字 为 "张三"
设 年龄 为 25

打印 名字
打印 年龄
```

- `设` 表示「我要创建一个变量」
- `名字` 是变量名（你可以自己起名）
- `为` 把右边的值放进左边

也可以用 `定义`，含义完全相同：

```段言
定义 体重 为 70
```

### 2.3 f-string 字符串插值

在字符串前面加 `f`，就可以用 `{}` 把变量嵌入文字中：

```段言
设 名字 为 "段言"
设 版本 为 1.11

打印(f"语言：{名字}，版本：{版本}")
```

输出：

```
语言：段言，版本：1.11
```

### 2.4 注释

以 `#` 开头的行是注释，程序执行时会跳过它。注释是给人看的说明文字：

```段言
# 这是一行注释
设 甲 为 10  # 这也是注释
打印 甲
```

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `打印` | 输出到屏幕 | `打印 "你好"` |
| `设 X 为 Y` | 创建变量 | `设 年龄 为 25` |
| `f"..."` | 字符串插值 | `f"我叫{名字}"` |
| `#` | 注释 | `# 说明文字` |

## 3. 基本运算

### 3.1 算术运算

```段言
设 甲 为 10
设 乙 为 3

打印(甲 加 乙)       # 加法 → 13
print(甲 减 乙)       # 减法 → 7
打印(甲 乘 乙)       # 乘法 → 30
print(甲 除 乙)       # 除法 → 3.333...
打印(甲 整除 乙)     # 整除 → 3
打印(甲 取余 乙)     # 取余 → 1
print(甲 幂 乙)       # 幂运算 → 1000
```

> **提示**：段言也支持 `print` 写法，与 `打印` 完全等价。

也支持中文数字字面量：

```段言
设 结果 为 三 加 五
打印 结果    # 输出: 8
```

### 3.2 比较运算

比较运算的结果是 `真`（成立）或 `假`（不成立）：

```段言
设 甲 为 10
设 乙 为 5

打印(甲 大于 乙)       # 真
print(甲 小于 乙)       # 假
打印(甲 等于 乙)       # 假
print(甲 不等于 乙)     # 真
打印(甲 大于等于 乙)   # 真
```

### 3.3 逻辑运算

在 `如果` 条件中，可以用 `且`（两个都满足）、`或`（满足其一即可）连接多个条件：

```段言
设 甲 为 10
设 乙 为 5
设 丙 为 3

如果 甲 大于 乙 且 乙 大于 丙：
    打印 "甲>乙>丙，条件链成立"
```

`非` 表示「取反」：

```段言
设 开关 为 假
如果 非 开关：
    打印 "开关是关闭的"
```

### 3.4 运算简写

修改变量自身时，用 `设 X 为 X 运算 Y` 的写法：

```段言
设 计数 为 0
设 计数 为 计数 加 1    # 计数变成 1
设 计数 为 计数 加 1    # 计数变成 2
打印 计数               # 输出: 2
```

### 小结

| 运算 | 段言写法 | 示例 |
|------|---------|------|
| 加 | `加` | `甲 加 乙` |
| 减 | `减` | `甲 减 乙` |
| 乘 | `乘` | `甲 乘 乙` |
| 除 | `除` | `甲 除 乙` |
| 取余 | `取余` | `甲 取余 乙` |
| 大于 | `大于` | `甲 大于 乙` |
| 等于 | `等于` | `甲 等于 乙` |
| 且 | `且` | `条件1 且 条件2` |
| 或 | `或` | `条件1 或 条件2` |
| 非 | `非` | `非 开关` |

## 4. 条件判断

### 4.1 如果...否则

条件判断让程序「看情况办事」：

```段言
设 分数 为 85

如果 分数 大于等于 60：
    打印 "及格"
否则：
    打印 "不及格"
```

### 4.2 多条件：否则如果

```段言
设 分数 为 85

如果 分数 大于等于 90：
    打印 "优秀"
否则如果 分数 大于等于 60：
    打印 "及格"
否则：
    打印 "不及格"
```

程序从上往下检查，一旦某个条件满足就执行对应代码块，不再往下检查。

### 4.3 嵌套条件

条件里面可以再嵌套条件：

```段言
设 甲 为 10
设 乙 为 20

如果 甲 大于 5：
    如果 乙 大于 15：
        打印 "两个条件都满足"
    否则：
        打印 "只有甲满足"
否则：
    打印 "都不满足"
```

### 4.4 三元表达式

简单二选一可以用一行写完：

```段言
设 数 为 10
设 结果 为 "偶数" 如果 数 取余 2 等于 0 否则 "奇数"
打印 结果    # 输出: 偶数
```

读法：`结果` 等于 `"偶数"`，**如果** 条件成立；**否则** 等于 `"奇数"`。

### 小结

| 语法 | 作用 |
|------|------|
| `如果 条件：` | 条件成立时执行 |
| `否则如果 条件：` | 上一个条件不满足时再判断 |
| `否则：` | 所有条件都不满足时执行 |
| `值 如果 条件 否则 值` | 一行二选一 |

> **注意**：条件行末尾的冒号 `：` 不能省略，代码块必须缩进（每层缩进 4 个空格或 1 个 Tab，保持一致即可）。

## 5. 循环

循环让程序重复执行一段代码，不用手动复制粘贴。

### 5.1 当循环（while）

`当` 相当于「只要条件成立，就一直做」：

```段言
设 计数 为 1
当 计数 小于等于 5：
    打印(f"第{计数}次")
    设 计数 为 计数 加 1
```

输出：

```
第1次
第2次
第3次
第4次
第5次
```

> **重要**：别忘了在循环体内更新计数变量，否则会变成无限循环！

### 5.2 遍历循环（for）

`遍历` 用于依次取出列表或范围中的每个元素：

```段言
遍历 项 于 1至5：
    打印 项
```

输出 `1` 到 `5`，每个数字一行。

`1至5` 表示从 1 到 5（含 5）。也可以指定步长：

```段言
遍历 项 于 1到10步2：
    打印 项
```

输出：`1 3 5 7 9`（每次跳 2）。

也可以遍历列表：

```段言
设 颜色 为 ["红", "绿", "蓝"]
遍历 色 于 颜色：
    打印 色
```

### 5.3 跳出和跳过

- `跳出`：立刻结束整个循环（相当于 break）
- `跳过`：跳过当前这一轮，直接进入下一轮（相当于 continue）

```段言
遍历 项 于 1至10：
    如果 项 取余 2 等于 0：
        跳过
    打印 项
```

输出：`1 3 5 7 9`（只打印奇数，偶数被跳过）。

```段言
遍历 项 于 1至10：
    如果 项 大于 5：
        跳出
    打印 项
```

输出：`1 2 3 4 5`（到 6 时跳出循环，不再执行）。

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `当 条件：` | 条件成立就重复 | `当 计数 小于 10：` |
| `遍历 X 于 范围：` | 依次遍历 | `遍历 i 于 1至5：` |
| `A至B` | 范围 A 到 B | `1至10` |
| `A到B步C` | 范围带步长 | `1到10步2` |
| `跳出` | 结束循环 | `跳出` |
| `跳过` | 跳过本轮 | `跳过` |

## 6. 段落（函数）

「段落」就是一段可以反复使用的代码。你把一段逻辑写成段落，以后调用它就行，不用重复写。

### 6.1 定义和调用

```段言
段落 问好 接收 名字：
    打印(f"你好，{名字}！")

问好("张三")
问好("李四")
```

- `段落` 表示「我要定义一个段落」
- `问好` 是段落名
- `接收 名字` 表示这个段落接收一个参数叫 `名字`

### 6.2 返回值

段落可以把结果「返回」给调用者：

```段言
段落 加法 接收 a, b：
    返回 a 加 b

设 结果 为 加法(3, 5)
打印 结果    # 输出: 8
```

`返回` 表示「把后面的值交出去，段落到此结束」。

### 6.3 递归

段落可以调用自己，这叫递归。经典例子是阶乘：

```段言
段落 阶乘 接收 n：
    如果 n 小于等于 1：
        返回 1
    返回 n 乘以 阶乘(n 减 1)

打印 阶乘(5)    # 输出: 120
```

执行过程：`阶乘(5)` → `5 * 阶乘(4)` → `5 * 4 * 阶乘(3)` → ... → `5 * 4 * 3 * 2 * 1 = 120`。

### 6.4 多参数

```段言
段落 创建名片 接收 姓名, 职业：
    返回 f"{姓名} - {职业}"

打印 创建名片("张三", "工程师")
```

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `段落 名 接收 参数：` | 定义段落 | `段落 加法 接收 a, b：` |
| `返回 值` | 返回结果 | `返回 a 加 b` |
| `名(参数)` | 调用段落 | `加法(3, 5)` |

## 7. 列表与字符串

### 7.1 列表

列表用于存储一组有序的数据：

```段言
设 水果 为 ["苹果", "香蕉", "橘子"]
打印 水果
```

**访问元素**（从 0 开始计数）：

```段言
设 水果 为 ["苹果", "香蕉", "橘子"]
打印 水果[0]    # 输出: 苹果
打印 水果[1]    # 输出: 香蕉
```

**添加元素**：

```段言
设 水果 为 ["苹果", "香蕉"]
列表追加(水果, "橘子")
打印 水果    # 输出: ['苹果', '香蕉', '橘子']
```

**列表长度**：

```段言
设 水果 为 ["苹果", "香蕉", "橘子"]
打印(长(水果))    # 输出: 3
```

**列表排序**：

```段言
设 数字 为 [3, 1, 4, 1, 5, 9, 2, 6]
数字.排序()
打印 数字    # 输出: [1, 1, 2, 3, 4, 5, 6, 9]
```

### 7.2 字符串

字符串就是一段文字，用引号包裹：

```段言
设 名字 为 "段言"
```

**拼接**：

```段言
设 问候 为 "你好，"
设 对象 为 "世界"
打印(问候 加上 对象)    # 输出: 你好，世界
```

**长度**：

```段言
设 名字 为 "段言"
打印(长(名字))    # 输出: 2
```

**访问字符**：

```段言
设 名字 为 "段言"
打印 名字[0]    # 输出: 段
```

**转换大小写**：

```段言
设 英文 为 "hello"
打印(转大写(英文))    # 输出: HELLO
print(转小写(英文))    # 输出: hello
```

### 7.3 列表推导

列表推导是一种用一行代码生成列表的简洁写法：

```段言
设 平方数 为 [x 乘以 x 遍历 x 之 1至5]
打印 平方数    # 输出: [1, 4, 9, 16, 25]
```

读法：`x 乘以 x`（每个元素的值），`遍历 x 之 1至5`（x 从 1 到 5）。

带条件筛选：

```段言
设 偶数 为 [x 遍历 x 之 1至10 若 x 取余 2 等于 0]
打印 偶数    # 输出: [2, 4, 6, 8, 10]
```

### 7.4 字典

字典用于存储键值对：

```段言
设 学生 为 {"名字": "张三", "年龄": 25}
打印 学生["名字"]    # 输出: 张三
打印 学生["年龄"]    # 输出: 25
```

添加新的键值对：

```段言
设 学生 为 {"名字": "张三"}
学生["年龄"] 为 25
打印 学生    # 输出: {'名字': '张三', '年龄': 25}
```

遍历字典：

```段言
设 学生 为 {"名字": "张三", "年龄": 25, "城市": "北京"}
遍历 键 于 学生：
    打印(f"{键}: {学生[键]}")
```

### 小结

| 操作 | 语法 | 示例 |
|------|------|------|
| 创建列表 | `[元素, 元素]` | `[1, 2, 3]` |
| 访问元素 | `列表[索引]` | `水果[0]` |
| 添加元素 | `列表追加(列表, 元素)` | `列表追加(水果, "橘子")` |
| 列表长度 | `长(列表)` | `长(水果)` |
| 字符串拼接 | `字符串 加上 字符串` | `"a" 加上 "b"` |
| 列表推导 | `[表达式 遍历 变量 之 范围]` | `[x 乘以 x 遍历 x 之 1至5]` |
| 字典 | `{"键": "值"}` | `{"名字": "张三"}` |

## 8. 类与对象

### 8.1 什么是类

「类」就像一个模具——你设计好模具，就能用它批量生产「对象」。

比如「动物」是一个类，具体的「小狗旺财」就是一个对象。

### 8.2 定义类并创建对象

```段言
类 动物：
    属性 名字

    构造 接收 名字：
        己.名字 为 名字

    段落 介绍：
        打印(f"我叫{己.名字}")

设 小狗 为 动物("旺财")
小狗.介绍()
```

- `类 动物：` — 定义一个叫 `动物` 的类
- `属性 名字` — 声明这个类有一个属性叫 `名字`
- `构造 接收 名字：` — 创建对象时接收名字参数
- `己.名字 为 名字` — 把参数赋值给对象自己的属性（`己` 相当于 Python 的 `self`）
- `段落 介绍：` — 定义一个方法
- `设 小狗 为 动物("旺财")` — 创建一个 `动物` 对象，起名叫旺财
- `小狗.介绍()` — 调用对象的方法

### 8.3 类继承

子类可以继承父类的所有属性和方法，还能添加自己的：

```段言
类 动物：
    属性 名字

    构造 接收 名字：
        己.名字 为 名字

    段落 介绍：
        打印(f"我叫{己.名字}")

类 狗 继承 动物：
    段落 叫声：
        打印 "汪汪汪"

类 猫 继承 动物：
    段落 叫声：
        打印 "喵喵喵"

设 小狗 为 狗("旺财")
小狗.介绍()    # 继承自动物类
小狗.叫声()    # 自己的方法

设 小猫 为 猫("咪咪")
小猫.介绍()
小猫.叫声()
```

输出：

```
我叫旺财
汪汪汪
我叫咪咪
喵喵喵
```

### 8.4 静态方法

静态方法不需要创建对象就能直接调用：

```段言
类 数学工具：
    静态 段落 平方 接收 x：
        返回 x 乘以 x

    静态 段落 立方 接收 x：
        返回 x 乘以 x 乘以 x

打印 数学工具.平方(5)    # 输出: 25
打印 数学工具.立方(3)    # 输出: 27
```

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `类 名：` | 定义类 | `类 动物：` |
| `属性 名` | 声明属性 | `属性 名字` |
| `构造 接收 参数：` | 构造方法 | `构造 接收 名字：` |
| `己.属性` | 访问自身属性 | `己.名字` |
| `类 子 继承 父：` | 继承 | `类 狗 继承 动物：` |
| `静态 段落 名：` | 静态方法 | `静态 段落 平方 接收 x：` |

## 9. 实战练习

### 9.1 猜数字游戏

程序预设一个数字，玩家猜大猜小都有提示，直到猜对为止。

为了演示方便，我们用固定值代替随机数。你也可以通过设置不同的猜测来体会逻辑：

```段言
设 目标 为 7
设 猜测 为 0
设 次数 为 0

当 猜测 不等于 目标：
    设 次数 为 次数 加 1

    如果 次数 等于 1：
        设 猜测 为 3
    否则如果 次数 等于 2：
        设 猜测 为 5
    否则：
        设 猜测 为 7

    如果 猜测 大于 目标：
        打印(f"第{次数}次：猜了{猜测}，太大了！")
    否则如果 猜测 小于 目标：
        打印(f"第{次数}次：猜了{猜测}，太小了！")
    否则：
        打印(f"第{次数}次：猜了{猜测}，猜对了！")

打印(f"总共猜了{次数}次")
```

输出：

```

第2次：猜了5，太小了！
第3次：猜了7，猜对了！
总共猜了3次
```

### 9.2 待办清单

用列表管理任务，支持添加和删除：

```段言

段落 添加任务 接收 任务：
    列表追加(待办列表, 任务)
    打印(f"已添加：{任务}")

        返回
    设 任务 为 待办列表[序号 减 1]

段落 显示待办：
    打印 "=== 待办清单 ==="
    如果 长(待办列表) 等于 0：

        返回
    设 序号 为 1
    遍历 任务 于 待办列表：

        设 序号 为 序号 加 1

添加任务("学习段言")

打印 ""

```

## 10. 异常处理

程序运行时难免出错——除以零、文件不存在、网络中断。异常处理让程序在出错时不崩溃，而是优雅地处理。

### 10.1 尝试...捕获

```段言
尝试：
    设 结果 为 10 除以 0
捕获 Exception 为 错误：
    打印("出错了：" 加上 转字符串(错误))
```

- `尝试：` — 包裹可能出错的代码
- `捕获 Exception 为 错误：` — 捕获异常并赋值给变量 `错误`

### 10.2 主动抛出异常

用 `抛出` 主动抛出异常：

```段言
段落 检查年龄 接收 年龄：
    如果 年龄 小于 0：
        抛出 Exception("年龄不能为负数")
    打印(f"年龄是{年龄}")

尝试：
    检查年龄(-5)
捕获 Exception 为 e：
    打印("捕获到异常：" 加上 转字符串(e))
```

### 10.3 最终块

`最终` 块无论是否出错都会执行，常用于资源清理：

```段言
尝试：
    设 数据 为 读取文件("config.txt")
    打印(数据)
捕获 Exception 为 e：
    打印("读取失败")
最终：
    打印("操作结束")
```

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `尝试：` | 包裹可能出错的代码 | `尝试：` |
| `捕获 Exception 为 变量：` | 捕获并处理异常 | `捕获 Exception 为 e：` |
| `抛出 Exception("消息")` | 主动抛出异常 | `抛出 Exception("出错了")` |
| `最终：` | 无论是否出错都执行 | `最终：` |

## 12. 模块系统

段言有丰富的标准库，用 `导入` 来加载模块。

### 12.1 导入模块

```段言
导入 数学

```

- `导入 数学` — 加载数学模块
- `数学.圆周率()` — 调用模块中的函数（注意加括号）

### 12.2 常用标准库

| 模块 | 功能 | 示例函数 |
|------|------|---------|
| 数学 | 数学运算、统计、随机数 | `圆周率()`、`平方根()`、`随机整数()` |
| 文件系统 | 文件和目录操作 | `写入文件()`、`读取文件()`、`文件存在()` |
| JSON | JSON 解析和序列化 | `解析JSON()`、`序列化JSON()` |
| 正则表达式 | 文本匹配和替换 | `匹配()`、`替换()` |
| CSV | CSV 文件处理 | `读取CSV()`、`写入CSV()` |

### 12.3 从模块导入函数

也可以只导入需要的函数：

```段言
从 数学 导入 平方根
```

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `导入 模块名` | 加载整个模块 | `导入 数学` |
| `模块名.函数名()` | 调用模块函数 | `数学.圆周率()` |
| `从 模块 导入 函数` | 只导入指定函数 | `从 数学 导入 平方根` |
