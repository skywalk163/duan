## 1. 环境准备

### 1.1 安装 Python

段言运行在 Python 之上，所以第一步是安装 Python（3.10 或更高版本）。

去 [python.org](https://www.python.org/downloads/) 下载安装包，运行时勾选 **Add Python to PATH**，一路「下一步」即可。

安装完成后，打开终端（Windows 按 `Win+R`，输入 `cmd` 回车），输入：

```bash
python --version
```

看到类似 `Python 3.12.x` 的输出就说明安装成功。

### 1.2 安装段言

在终端中执行：

```bash
pip install duan
```

### 1.3 验证安装

```bash
duan --version
```

看到 `段言编译器 v6.x.x` 说明安装成功。

现在创建一个测试文件 `hello.duan`，写入以下内容：

```段言
打印 "你好，段言！"
```

然后运行：

```bash
duan run hello.duan
```

如果终端输出 `你好，段言！`，恭喜你——环境搭建完毕！

### 小结

| 命令 | 作用 |
|------|------|
| `pip install duan` | 安装段言 |
| `duan --version` | 查看版本 |
| `duan run 文件名.duan` | 运行段言程序 |

## 2. 第一个程序

### 2.1 打印

`打印` 是段言最常用的命令，作用是把内容显示到屏幕上：

```段言
打印 "你好，世界！"
```

你也可以用括号写法，效果一样：

```段言
打印("你好，世界！")
```

### 2.2 变量

变量就像一个「盒子」，可以存放数据。段言使用 `设` 关键字声明变量：

```段言
设 名字 为 "张三"
设 年龄 为 25

打印 名字
打印 年龄
```

- `设` 表示「我要创建一个变量」
- `名字` 是变量名（你可以自己起名）
- `为` 把右边的值放进左边

> **句号说明**：段言语句末尾的句号「。」是**可选的**——加了不影响运行，不加也完全没问题。本教程的示例一律不加句号，保持简洁。

### 2.3 f-string 字符串插值

在字符串前面加 `f`，就可以用 `{}` 把变量嵌入文字中：

```段言
设 名字 为 "段言"
设 版本 为 1.11

打印(f"语言：{名字}，版本：{版本}")
```

输出：

```
语言：段言，版本：1.11
```

### 2.4 注释

以 `#` 开头的行是注释，程序执行时会跳过它。注释是给人看的说明文字：

```段言
# 这是一行注释
设 甲 为 10  # 这也是注释
打印 甲
```

### 小结

| 语法 | 作用 | 示例 |
|------|------|------|
| `打印` | 输出到屏幕 | `打印 "你好"` |
| `设 X 为 Y` | 创建变量 | `设 年龄 为 25` |
| `f"..."` | 字符串插值 | `f"我叫{名字}"` |
| `#` | 注释 | `# 说明文字` |

## 3. 基本运算

### 3.1 算术运算

段言同时支持**符号运算符**和**中文运算符**，两者完全等价。推荐使用符号写法（更简洁）：

```段言
设 甲 为 10
设 乙 为 3

打印(甲 + 乙)       # 加法 → 13    等价于：甲 加 乙
打印(甲 - 乙)       # 减法 → 7     等价于：甲 减 乙
打印(甲 * 乙)       # 乘法 → 30    等价于：甲 乘 乙
打印(甲 / 乙)       # 除法 → 3.333...  等价于：甲 除 乙
打印(甲 // 乙)      # 整除 → 3     等价于：甲 整除 乙
打印(甲 % 乙)       # 取余 → 1     等价于：甲 取余 乙
打印(甲 ** 乙)      # 幂运算 → 1000    等价于：甲 幂 乙
```

### 3.2 比较运算

比较运算的结果是 `真`（成立）或 `假`（不成立）。符号和中文写法均可：

```段言
设 甲 为 10
设 乙 为 5

打印(甲 > 乙)        # 真    等价于：甲 大于 乙
打印(甲 < 乙)        # 假    等价于：甲 小于 乙
打印(甲 == 乙)       # 假    等价于：甲 等于 乙
打印(甲 != 乙)       # 真    等价于：甲 不等于 乙
打印(甲 >= 乙)       # 真    等价于：甲 大于等于 乙
```

### 3.3 逻辑运算

在 `如果` 条件中，可以用 `且`（两个都满足）、`或`（满足其一即可）连接多个条件：

```段言
设 甲 为 10
设 乙 为 5
设 丙 为 3

如果 甲 > 乙 且 乙 > 丙：
    打印 "甲>乙>丙，条件链成立"
```

`非` 表示「取反」：

```段言
设 开关 为 假
如果 非 开关：
    打印 "开关是关闭的"
```

### 3.4 运算简写

修改变量自身时，直接用 `=` 重新赋值即可：

```段言
设 计数 为 0
计数 = 计数 + 1    # 计数变成 1
计数 = 计数 + 1    # 计数变成 2
打印 计数           # 输出: 2
```

### 小结

| 运算 | 符号写法 | 中文写法 | 示例（符号） |
|------|---------|---------|-------------|
| 加 | `+` | `加` / `加上` | `甲 + 乙` |
| 减 | `-` | `减` / `减去` | `甲 - 乙` |
| 乘 | `*` | `乘` / `乘以` | `甲 * 乙` |
| 除 | `/` | `除` / `除以` | `甲 / 乙` |
| 整除 | `//` | `整除` | `甲 // 乙` |
| 取余 | `%` | `取余` / `模` | `甲 % 乙` |
| 幂 | `**` | `幂` / `幂以` | `甲 ** 乙` |
| 大于 | `>` | `大于` | `甲 > 乙` |
| 小于 | `<` | `小于` | `甲 < 乙` |
| 等于 | `==` | `等于` | `甲 == 乙` |
| 不等于 | `!=` | `不等于` | `甲 != 乙` |
| 大于等于 | `>=` | `大于等于` | `甲 >= 乙` |
| 小于等于 | `<=` | `小于等于` | `甲 <= 乙` |
| 且 | — | `且` / `与` | `条件1 且 条件2` |
| 或 | — | `或` | `条件1 或 条件2` |
| 非 | — | `非` | `非 开关` |

## 4. 条件判断

### 4.1 如果...否则

条件判断让程序「看情况办事」：

```段言
设 分数 为 85

如果 分数 >= 60：
    打印 "及格"
否则：
    打印 "不及格"
```

### 4.2 多条件：否则如果

```段言
设 分数 为 85

如果 分数 >= 90：
    打印 "优秀"
否则如果 分数 >= 60：
    打印 "及格"
否则：
    打印 "不及格"
```

### 4.3 三元表达式

简单二选一可以用一行写完：

```段言
设 数 为 10
设 结果 为 "偶数" 如果 数 % 2 == 0 否则 "奇数"
打印 结果    # 输出: 偶数
```

## 5. 循环

### 5.1 当循环（while）

`当` 相当于「只要条件成立，就一直做」：

```段言
设 计数 为 1
当 计数 <= 5：
    打印(f"第{计数}次")
    计数 = 计数 + 1
```

### 5.2 遍历循环（for）

`遍历` 用于依次取出列表或范围中的每个元素：

```段言
遍历 项 在 1 到 5：
    打印 项
```

也可以遍历列表：

```段言
设 颜色 为 ["红", "绿", "蓝"]
遍历 颜色 为 色：
    打印 色
```

### 5.3 跳出和跳过

- `跳出`：立刻结束整个循环（相当于 break）
- `跳过`：跳过当前这一轮，直接进入下一轮（相当于 continue）

```段言
遍历 项 在 1 到 10：
    如果 项 % 2 == 0：
        跳过
    打印 项
```

## 6. 段落（函数）

### 6.1 定义和调用

段言使用 `段落` 关键字定义函数：

```段言
段落 问好 接收 名字：
    打印(f"你好，{名字}！")

问好("张三")
```

### 6.2 返回值

函数可以把结果「返回」给调用者：

```段言
段落 加法 接收 a, b：
    返回 a + b

设 结果 为 加法(3, 5)
打印 结果    # 输出: 8
```

### 6.3 递归

函数可以调用自己，这叫递归：

```段言
段落 阶乘 接收 n：
    如果 n <= 1：
        返回 1
    返回 n * 阶乘(n - 1)

打印 阶乘(5)    # 输出: 120
```

## 7. 列表与字符串

### 7.1 列表

```段言
设 水果 为 ["苹果", "香蕉", "橘子"]
打印 水果[0]    # 输出: 苹果
水果.追加("橘子")
打印 长度(水果)  # 输出: 3
```

### 7.2 字符串

```段言
设 名字 为 "段言"
打印 长度(名字)  # 输出: 2
打印 名字[0]    # 输出: 段
```

### 7.3 列表推导

```段言
设 平方数 为 [x * x 遍历 x 之 范围(1, 6)]
打印 平方数    # 输出: [1, 4, 9, 16, 25]
```

### 7.4 字典

```段言
设 学生 为 {"名字": "张三", "年龄": 25}
打印 学生["名字"]    # 输出: 张三
```

## 9. 实战练习

### 9.1 猜数字游戏

```段言
设 目标 为 7
设 猜测 为 0
设 次数 为 0

当 猜测 != 目标：
    次数 = 次数 + 1
    如果 次数 == 1：
        猜测 = 3
    否则如果 次数 == 2：
        猜测 = 5
    否则：
        猜测 = 7

    如果 猜测 > 目标：
        打印(f"第{次数}次：猜了{猜测}，太大了！")
    否则如果 猜测 < 目标：
        打印(f"第{次数}次：猜了{猜测}，太小了！")
    否则：
        打印(f"第{次数}次：猜了{猜测}，猜对了！")
```

### 9.2 待办清单

```段言
设 待办列表 为 []

段落 添加任务 接收 任务：
    待办列表.追加(任务)
    打印(f"已添加：{任务}")

段落 显示待办 接收：
    打印 "=== 待办清单 ==="
    如果 长度(待办列表) == 0：
        打印 "（空）"
        返回
    设 序号 为 1
    遍历 待办列表 为 任务：
        打印(f"  {序号}. {任务}")
        序号 = 序号 + 1

添加任务("学习段言")
添加任务("写一个程序")
显示待办()
```

### 9.3 FizzBuzz

```段言
遍历 n 在 1 到 15：
    如果 n % 15 == 0：
        打印 "FizzBuzz"
    否则如果 n % 3 == 0：
        打印 "Fizz"
    否则如果 n % 5 == 0：
        打印 "Buzz"
    否则：
        打印 n
```

## 10. 异常处理

### 10.1 尝试...捕获

```段言
尝试：
    设 结果 为 10 / 0
捕获 错误：
    打印("出错了：" + 转字符串(错误))
```

### 10.2 主动抛出异常

```段言
段落 检查年龄 接收 年龄：
    如果 年龄 < 0：
        抛出 "年龄不能为负数"
    打印(f"年龄是{年龄}")

尝试：
    检查年龄(-5)
捕获 e：
    打印("捕获到异常：" + 转字符串(e))
```

### 10.3 最终块

```段言
尝试：
    设 数据 为 读取文件("config.txt")
    打印(数据)
捕获 e：
    打印("读取失败")
最终：
    打印("操作结束")
```
