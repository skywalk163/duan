# 运算符参考

## 算术运算符

| 符号 | 中文别名 | 说明 |
|------|---------|------|
| `+` | `加` | 加法 |
| `-` | `减` | 减法 |
| `*` | `乘` | 乘法 |
| `/` | `除` | 除法 |
| `%` | `模` | 取模 |
| `**` | `幂` | 幂运算 |
| `//` | | 整除 |

## 比较运算符

| 符号 | 中文别名 | 说明 |
|------|---------|------|
| `>` | `大于` | 大于 |
| `<` | `小于` | 小于 |
| `>=` | `大于等于` | 大于等于 |
| `<=` | `小于等于` | 小于等于 |
| `==` | `等于` | 等于 |
| `!=` | `不等于` | 不等于 |

## 赋值运算符

| 符号 | 中文别名 | 说明 |
|------|---------|------|
| `=` | `设为` | 赋值 |
| `+=` | `加上` | 加后赋值 |
| `-=` | `减去` | 减后赋值 |
| `*=` | `乘以` | 乘后赋值 |
| `/=` | `除以` | 除后赋值 |

## 逻辑运算符

| 关键字 | 说明 |
|--------|------|
| `且` | 逻辑与 (and) |
| `或` | 逻辑或 (or) |
| `非` | 逻辑非 (not) |

## 运算符优先级

从高到低：

1. `**`（幂运算）
2. `非`（逻辑非）
3. `*` `/` `%` `//` `乘` `除` `模`
4. `+` `-` `加` `减`
5. `>` `<` `>=` `<=` `==` `!=`（比较）
6. `且`（逻辑与）
7. `或`（逻辑或）
8. `=` `+=` `-=` `*=` `/=`（赋值）
