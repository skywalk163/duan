# 进阶教程

> 适合已有编程基础的段言用户，深入掌握 FFI 外部函数接口、Web 应用开发、并发编程等高级主题。

## 1. FFI 与 C 交互

段言支持通过 FFI（外部函数接口）直接调用 C 语言函数，实现高性能计算和系统级编程。

### 1.1 加载动态库

```段言
# 加载系统数学库
加载库 "libc.so.6" 为 数学库
# 在 Windows 上使用 "msvcrt.dll"
# 加载库 "msvcrt.dll" 为 数学库

外部 段落 正弦 接收 甲: 小数 返回 小数 在 数学库
外部 段落 余弦 接收 甲: 小数 返回 小数 在 数学库
外部 段落 平方根 接收 甲: 小数 返回 小数 在 数学库

设 结果 为 正弦(3.14159 / 2)
打印 "sin(π/2) = " + 转字符串(结果)

设 结果2 为 平方根(144.0)
打印 "sqrt(144) = " + 转字符串(结果2)
```

### 1.2 使用 @C 语法糖

段言提供 `@C` 语法糖，简化 FFI 声明：

```段言
# 使用 @C 声明外部函数
@C 段落 正弦 接收 甲: 小数 返回 小数 在 数学库
@C 段落 余弦 接收 甲: 小数 返回 小数 在 数学库

# 结构化类型声明
@C 结构体 点 { x: 小数, y: 小数 }

@C 枚举 颜色 { 红 = 0, 绿 = 1, 蓝 = 2 }

# 加载库
@C 加载库 "libc.so.6" 为 数学库
```

### 1.3 结构体与指针

```段言
# 定义 C 结构体
@C 结构体 时间结构 {
    年: 整数,
    月: 整数,
    日: 整数,
    时: 整数,
    分: 整数,
    秒: 整数
}

# 获取当前时间
外部 段落 获取当前时间 接收 指针 返回 整数 在 数学库

# 内存操作
外部 段落 内存分配 接收 大小: 整数 返回 指针 在 数学库
外部 段落 内存释放 接收 指针 返回 空 在 数学库

# 指针操作
设 缓冲区 为 内存分配(1024)
打印 "分配了 1024 字节内存"

# 使用完后释放
内存释放(缓冲区)
打印 "内存已释放"
```

### 1.4 回调函数

```段言
# 定义回调类型
@C 回调 比较函数 接收 甲: 指针, 乙: 指针 返回 整数

# 使用回调
外部 段落 快速排序 接收 数组: 指针, 数量: 整数, 大小: 整数, 比较: 比较函数 返回 空 在 数学库

段落 整数比较 接收 甲, 乙:
    设 甲值 为 解引用(甲)
    设 乙值 为 解引用(乙)
    如果 甲值 < 乙值:
        返回 -1
    否则如果 甲值 > 乙值:
        返回 1
    否则:
        返回 0

打印 "C 回调函数已就绪"
```

### 1.5 调试 FFI 调用

```段言
# 启用 FFI 调试
外部 调试 { 开启, 记录调用, 记录类型 }

# 运行时调试控制
启用调试()
打印 "FFI 调试模式已启用"

# 执行一些 FFI 调用
设 结果 为 正弦(1.0)

# 获取调试日志
设 日志 为 获取日志()
打印 "FFI 调用日志："
打印 日志

# 禁用调试
禁用调试()
```

## 2. Web 应用开发

### 2.1 创建 HTTP 服务器

```段言
从 贡献.HTTP服务端 导入 创建服务器, 路由, 请求, 响应

段落 首页 接收 请求:
    返回 响应(200, {"内容类型": "text/html"}, "<h1>欢迎使用段言！</h1>")

段落 用户信息 接收 请求:
    设 用户ID 为 请求.参数["id"]
    返回 响应(200, {"内容类型": "application/json"},
        "{\"id\": " + 用户ID + ", \"name\": \"张三\"}")

段落 提交数据 接收 请求:
    设 数据 为 请求.主体
    打印 "收到数据：" + 数据
    返回 响应(201, {"内容类型": "text/plain"}, "数据已接收")

# 配置路由
设 路由表 为 路由()
路由表.添加("GET", "/", 首页)
路由表.添加("GET", "/用户", 用户信息)
路由表.添加("POST", "/数据", 提交数据)

# 启动服务器
设 服务器 为 创建服务器("0.0.0.0", 8080, 路由表)
打印 "服务器已启动：http://localhost:8080"
服务器.启动()
```

### 2.2 HTTP 客户端请求

```段言
# 自定义请求

    头信息={"内容类型": "application/json", "授权": "Bearer token123"})
打印 "更新结果：" + 转字符串(响应3.状态码)
```

### 2.5 完整的 Web API 应用

```段言
从 贡献.HTTP服务端 导入 创建服务器, 路由, 请求, 响应
从 JSON 导入 解析JSON, 序列化JSON
从 日期时间 导入 当前时间

# 内存数据库
设 用户列表 为 []
设 下一个ID 为 1

段落 获取所有用户 接收 请求:
    返回 响应(200, {"内容类型": "application/json"},
        序列化JSON(用户列表))

段落 创建用户 接收 请求:
    设 数据 为 解析JSON(请求.主体)
    设 新用户 为 {"id": 下一个ID, "姓名": 数据["姓名"], "邮箱": 数据["邮箱"]}
    设 下一个ID 为 下一个ID + 1
    用户列表.追加(新用户)
    返回 响应(201, {"内容类型": "application/json"},
        序列化JSON(新用户))

段落 获取用户详情 接收 请求:
    设 用户ID 为 转整数(请求.参数["id"])
    遍历 用户列表 为 用户:
        如果 用户["id"] == 用户ID:
            返回 响应(200, {"内容类型": "application/json"},
                序列化JSON(用户))
    返回 响应(404, {"内容类型": "application/json"},
        "{\"error\": \"用户未找到\"}")

段落 健康检查 接收 请求:
    返回 响应(200, {"内容类型": "application/json"},
        "{\"status\": \"ok\", \"time\": " + 转字符串(当前时间()) + "}")

# 路由配置
设 路由表 为 路由()
路由表.添加("GET", "/api/users", 获取所有用户)
路由表.添加("POST", "/api/users", 创建用户)
路由表.添加("GET", "/api/users/:id", 获取用户详情)
路由表.添加("GET", "/health", 健康检查)

# 启动
设 服务器 为 创建服务器("0.0.0.0", 3000, 路由表)
打印 "RESTful API 服务已启动：http://localhost:3000"
打印 "可用端点："
打印 "  GET    /api/users      - 获取所有用户"
打印 "  POST   /api/users      - 创建用户"
打印 "  GET    /api/users/:id  - 获取用户详情"
打印 "  GET    /health         - 健康检查"
服务器.启动()
```

## 3. 并发编程

### 3.1 异步函数

```段言
异步 段落 获取数据 接收 url:
    打印 "正在获取：" + url

    返回 "数据来自：" + url

异步 段落 主程序 接收:
    设 结果1 为 等待 获取数据("https://api.example.com/data1")

    打印 结果1
    打印 结果2

# 运行异步主程序
等待 主程序()
```

### 3.2 并行执行

```段言
段落 耗时任务 接收 名称, 时间:
    打印 名称 + " 开始执行"
    休眠(时间)  # 模拟耗时操作
    打印 名称 + " 执行完成"
    返回 名称 + " 的结果"

# 并行执行多个任务
并行 {
    设 结果1 为 耗时任务("任务A", 2)
    设 结果2 为 耗时任务("任务B", 3)
    设 结果3 为 耗时任务("任务C", 1)
}

打印 "所有任务已完成！"
打印 结果1

打印 结果3
```

## 4. 测试与调试

### 4.1 单元测试

```段言
从 贡献.单元测试框架 导入 测试, 断言相等, 断言真, 运行测试

段落 加法 接收 甲, 乙:
    返回 甲 + 乙

段落 除法 接收 甲, 乙:
    如果 乙 == 0:
        抛出 "除数不能为零"
    返回 甲 / 乙

# 测试用例
段落 测试加法 接收:
    断言相等(加法(2, 3), 5)
    断言相等(加法(-1, 1), 0)
    断言相等(加法(0, 0), 0)
    打印 "测试加法通过 ✓"

段落 测试除法 接收:
    断言相等(除法(10, 2), 5)
    断言相等(除法(7, 2), 3.5)
    打印 "测试除法通过 ✓"

段落 测试除零错误 接收:
    尝试:
        除法(1, 0)
        打印 "测试失败：未抛出异常 ✗"
    捕获:
        打印 "测试除零错误通过 ✓"

# 运行所有测试
测试加法()
测试除法()
测试除零错误()
```

### 4.2 使用调试器

```段言
# 在代码中设置断点
设 甲 为 10
设 乙 为 20
设 结果 为 甲 + 乙

# 打印调试信息
调试_打印("甲 = " + 转字符串(甲))
调试_打印("乙 = " + 转字符串(乙))
调试_打印("结果 = " + 转字符串(结果))

# 条件断点
如果 结果 > 30:
    调试_中断("结果超过预期")
```
