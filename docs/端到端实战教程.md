# 段言端到端实战：从零构建一个天气查询程序

本教程带你从零开始，用段言语言构建一个完整的天气查询程序。涵盖 duanpub 库导入、文件操作、异常处理和 Python 代码转译。

## 前置要求

- 已阅读《30分钟入门段言》，掌握变量、条件、循环、函数的基本用法
- 安装段言运行时（`pip install duan-lang` 或从源码构建）

## 第1步：环境准备

### 安装段言

```bash

cd C:\dumatework\duan
pip install -e .
```

## 第3步：使用 duanpub 导入库

段言通过 `导入` 关键字引入标准库模块。duanpub 是段言的标准库包管理器，提供 109 个包、2700+ 函数。

### 导入标准库

```duan
# 导入文件系统模块
导入 文件系统。

# 导入 JSON 处理模块
导入 JSON。

# 导入正则表达式模块
导入 正则表达式。
```

导入后，模块中的函数可以直接调用：

```duan
导入 文件系统。
导入 JSON。

# 写入文件
写入文件("test.txt", "你好段言")。

# 读取文件
设 内容 为 读取文件("test.txt")。
打印(内容)。

# JSON 解析
设 数据 为 解析JSON('{"name": "段言", "version": 1}')。
打印(数据["name"])。
```

### 从模块导入特定函数

```duan
从 HTTP客户端 导入 获取。
从 HTTP客户端 导入 发布。
```

### 模块系统说明

段言的模块系统与 Python 兼容：
- `导入 X` — 导入整个模块 X
- `从 X 导入 Y` — 从模块 X 导入函数 Y
- `导出 函数名` — 声明模块对外导出的函数

## 第4步：构建天气查询函数

我们来构建一个天气查询程序的核心函数。

### 定义查询函数

```duan
段落 查询天气(城市名):
    # 模拟 API 响应（实际使用时替换为真实 HTTP 调用）
    设 模拟响应 为 '{"city": "' 加上 城市名 加上 '", "temperature": 25, "condition": "晴"}'。
    
    # 解析 JSON 响应
    设 数据 为 解析JSON(模拟响应)。
    
    # 提取字段
    设 温度 为 数据["temperature"]。
    设 天气 为 数据["condition"]。
    
    # 格式化输出
    打印(城市名 加上 ": " 加上 串(温度) 加上 "C, " 加上 天气)。
    
    返回 数据。
结束。
```

### 调用函数

```duan
设 结果 为 查询天气("北京")。
```

输出：
```
北京: 25C, 晴
```

### 函数说明

- `串(值)` — 将任意值转为字符串（等同于 Python 的 `str()`）
- `加上` — 字符串拼接运算符
- `解析JSON(文本)` — 将 JSON 字符串解析为字典
- `打印(值)` — 输出到控制台

## 第5步：文件操作

天气查询结果应该保存到文件中，方便后续查看。

### 保存查询记录

```duan
段落 保存查询(城市名, 数据):
    # 拼接记录行
    设 记录 为 城市名 加上 "," 加上 串(数据["temperature"]) 加上 "," 加上 数据["condition"] 加上 "\n"。
    
    # 追加写入文件
    追加文件("history.txt", 记录)。
    
    打印("已保存查询记录")。
结束。
```

### 读取历史记录

```duan
段落 读取历史():
    如果 文件存在("history.txt") 那么:
        设 内容 为 读取文件("history.txt")。
        打印("--- 历史查询记录 ---")。
        打印(内容)。
    否则:
        打印("暂无历史记录")。
    结束。
结束。
```

### 文件操作函数一览

| 函数 | 参数 | 说明 |
|------|------|------|
| `读取文件(路径)` | 1 | 读取文本文件内容 |
| `写入文件(路径, 内容)` | 2 | 写入文本文件（覆盖） |
| `追加文件(路径, 内容)` | 2 | 追加写入文本文件 |
| `文件存在(路径)` | 1 | 判断文件是否存在 |
| `目录存在(路径)` | 1 | 判断目录是否存在 |
| `创建目录(路径)` | 1 | 创建目录 |
| `列出目录(路径)` | 1 | 列出目录内容 |

## 第6步：异常处理

网络请求和文件操作可能出错，需要用异常处理保护。

### 基本异常处理

```duan
尝试:
    设 结果 为 查询天气("北京")。
    保存查询("北京", 结果)。
捕获 Exception 为 e:
    打印("查询失败: " 加上 串(e))。
最终:
    打印("查询流程结束")。
结束。
```

### 多异常捕获

```duan
尝试:
    设 内容 为 读取文件("data.txt")。
    设 数据 为 解析JSON(内容)。
    打印(数据["name"])。
捕获 Exception 为 e:
    打印("处理失败: " 加上 串(e))。
结束。
```

### 异常处理关键字

| 关键字 | 说明 |
|--------|------|
| `尝试` | 开始异常处理块 |
| `捕获 异常类型 为 变量` | 捕获指定类型的异常 |
| `最终` | 无论是否异常都会执行的代码 |
| `抛出 异常` | 主动抛出异常 |

## 第7步：用转译器迁移 Python 项目

段言提供了 Python 到段言的转译器，可以将现有 Python 代码转换为段言代码。

### 安装转译器

转译器位于 `tools/ai_copilot/pyproject2duan.py`，无需额外安装。

### 转换单个文件

```bash
python tools/ai_copilot/pyproject2duan.py path/to/your_script.py
```

### 转换整个项目

```bash
python tools/ai_copilot/pyproject2duan.py path/to/your_project/ --verbose
```

转译器会：
1. 遍历项目中所有 `.py` 文件
2. 转换为 `.duan` 文件，保留目录结构
3. 生成 `duan.json` 项目配置
4. 生成 `CONVERSION_REPORT.md` 转换报告

### 转译示例

Python 代码：
```python
import json

def get_weather(city):
    data = {"city": city, "temp": 25}
    return json.dumps(data)

result = get_weather("北京")
print(result)
```

转译为段言：
```duan
导入 JSON。

段落 获取天气(城市):
    设 数据 为 {"city": 城市, "temp": 25}。
    返回 序列化JSON(数据)。
结束。

设 结果 为 获取天气("北京")。
打印(结果)。
```

### 检查转译报告

转译完成后查看 `CONVERSION_REPORT.md`：
- 成功转换的文件列表
- 需要手动修复的部分
- 不支持的语法特性

### 转译器已知限制

- 链式方法调用 `a.b.c()` 可能转译不完整
- `@staticmethod`、`@property` 等装饰器需要手动处理
- `async/await` 语法需要手动改为 `异步/等待`
- `match-case` 语法转译为 `if-else`
