# 段言端到端实战：从零构建一个天气查询程序

本教程带你从零开始，用段言语言构建一个完整的天气查询程序。涵盖 duanpub 库导入、文件操作、异常处理和 Python 代码转译。

## 前置要求

- 已阅读《30分钟入门段言》，掌握变量、条件、循环、函数的基本用法
- 安装段言运行时（`pip install duan-lang` 或从源码构建）

## 第2步：基础语法回顾

如果已经熟悉段言基础语法，可跳过本步。以下是核心语法速查：

```段言
# 变量声明
令 名字 = "段言"
令 年龄 = 18

# 条件判断
如果 年龄 > 18:
    打印 "成年"
否则:
    打印 "未成年"

# 遍历循环
遍历 项 在 [1, 2, 3]:
    打印 项

# 函数定义
函数 问候(名字):
    返回 "你好, " + 名字
```

**语法风格说明**（v3.4）：
- `令 x = 值` 是推荐的变量声明方式（`设 X 为 Y` 也兼容）
- 符号运算符 `+ - * /` 是推荐写法（`加 减 乘 除` 等中文运算符也兼容）
- 句号「。」是可选的，不需要每行末尾都加
- `函数 name(params):` 是推荐的函数定义方式（`段落` 也兼容）

更多细节请参考《30分钟入门段言》。

## 第3步：使用 duanpub 导入库

```段言
# 写入文件

# 读取文件
令 内容 = 读取文件("test.txt")
打印 内容

# JSON 解析
令 数据 = 解析JSON('{"name": "段言", "version": 1}')
打印 数据["name"]
```

### 从模块导入特定函数

```段言

```

### 导入外部语言库（v3.4 新增）

段言支持导入 Python 和 C 语言库：

### 模块系统说明

段言的模块系统与 Python 兼容：
- `导入 X` — 导入整个模块 X

## 第4步：构建天气查询函数

我们来构建一个天气查询程序的核心函数。

### 定义查询函数

```段言
函数 查询天气(城市名):
    # 模拟 API 响应（实际使用时替换为真实 HTTP 调用）
    令 模拟响应 = '{"city": "' + 城市名 + '", "temperature": 25, "condition": "晴"}'
    
    # 解析 JSON 响应
    令 数据 = 解析JSON(模拟响应)
    
    # 提取字段
    令 温度 = 数据["temperature"]
    令 天气 = 数据["condition"]
    
    # 格式化输出
    打印 城市名 + ": " + 转字符串(温度) + "C, " + 天气
    
    返回 数据
```

### 调用函数

```段言
令 结果 = 查询天气("北京")
```

输出：
```
北京: 25C, 晴
```

### 函数说明

- `转字符串(值)` — 将任意值转为字符串（等同于 Python 的 `str()`）
- `+` — 字符串拼接运算符（也支持中文写法 `加上`）
- `解析JSON(文本)` — 将 JSON 字符串解析为字典
- `打印(值)` — 输出到控制台

## 第5步：文件操作

天气查询结果应该保存到文件中，方便后续查看。

### 保存查询记录

```段言
函数 保存查询(城市名, 数据):
    # 拼接记录行
    令 记录 = 城市名 + "," + 转字符串(数据["temperature"]) + "," + 数据["condition"] + "\n"
    
    # 追加写入文件
    追加文件("history.txt", 记录)
    
    打印 "已保存查询记录"
```

### 读取历史记录

```段言
函数 读取历史():
    如果 文件存在("history.txt"):
        令 内容 = 读取文件("history.txt")
        打印 "--- 历史查询记录 ---"
        打印 内容
    否则:
        打印 "暂无历史记录"
```

### 文件操作函数一览

| 函数 | 参数 | 说明 |
|------|------|------|
| `读取文件(路径)` | 1 | 读取文本文件内容 |
| `写入文件(路径, 内容)` | 2 | 写入文本文件（覆盖） |
| `追加文件(路径, 内容)` | 2 | 追加写入文本文件 |
| `文件存在(路径)` | 1 | 判断文件是否存在 |
| `目录存在(路径)` | 1 | 判断目录是否存在 |
| `创建目录(路径)` | 1 | 创建目录 |
| `列出目录(路径)` | 1 | 列出目录内容 |

## 第6步：异常处理

网络请求和文件操作可能出错，需要用异常处理保护。

### 基本异常处理

```段言
尝试:
    令 结果 = 查询天气("北京")
    保存查询("北京", 结果)
捕获 Exception 为 e:
    打印 "查询失败: " + 转字符串(e)
最终:
    打印 "查询流程结束"
```

### 多异常捕获（v3.3 新增）

段言支持无括号的多异常捕获语法：

```段言
尝试:
    令 内容 = 读取文件("data.txt")
    令 数据 = 解析JSON(内容)
    打印 数据["name"]
捕获 FileNotFoundError, JSONDecodeError 为 e:
    打印 "文件或格式错误: " + 转字符串(e)
```

### 异常处理关键字

| 关键字 | 说明 |
|--------|------|
| `尝试` | 开始异常处理块 |
| `捕获 异常类型 为 变量` | 捕获指定类型的异常 |
| `捕获 类型A, 类型B 为 变量` | 捕获多种异常类型（v3.3） |
| `最终` | 无论是否异常都会执行的代码 |
| `抛出 异常` | 主动抛出异常 |

## 第7步：用转译器迁移 Python 项目

段言提供了 Python 到段言的转译器，可以将现有 Python 代码转换为段言代码。

### 安装转译器

转译器位于 `tools/ai_copilot/pyproject2duan.py`，无需额外安装。

### 转换单个文件

```bash
python tools/ai_copilot/pyproject2duan.py path/to/your_script.py
```

### 转换整个项目

```bash
python tools/ai_copilot/pyproject2duan.py path/to/your_project/ --verbose
```

转译器会：
1. 遍历项目中所有 `.py` 文件
2. 转换为 `.duan` 文件，保留目录结构
3. 生成 `duan.json` 项目配置
4. 生成 `CONVERSION_REPORT.md` 转换报告

### 转译示例

Python 代码：
```python
import json

def get_weather(city):
    data = {"city": city, "temp": 25}
    return json.dumps(data)

result = get_weather("北京")
print(result)
```

转译为段言：
```段言
导入 JSON

函数 获取天气(城市):
    令 数据 = {"city": 城市, "temp": 25}
    返回 序列化JSON(数据)

令 结果 = 获取天气("北京")
打印 结果
```

### 转译器覆盖范围

转译器已完整支持以下 Python 语法的原生转译（无需手动处理）：

| Python 语法 | 段言输出 | 状态 |
|-------------|---------|------|
| `match-case` | `匹配/情况` | 已支持 |
| `async def` | `异步 函数` | 已支持 |
| `async for` | `异步 遍历` | 已支持 |
| `async with` | `异步 使用` | 已支持 |
| `await expr` | `等待 <expr>` | 已支持 |
| `@staticmethod` | `静态 函数` | 已支持 |
| `@classmethod` | `类方法 函数` | 已支持 |
| `@property` | `特性 函数` | 已支持 |
| `@custom_decorator` | `标注 custom_decorator` | 已支持 |
| `@decorator(args)` | `标注 decorator(args)` | 已支持 |

### 检查转译报告

转译完成后查看 `CONVERSION_REPORT.md`：
- 成功转换的文件列表
- 需要手动修复的部分
- 不支持的语法特性

### 嵌入块（v3.3 新增）

对于段言暂不支持的 Python 语法，可以使用嵌入块直接引用原始代码：

```段言
令 数据 = [1, 2, 3]

嵌入 Python:
    result = [x**2 for x in 数据 if x > 1]
    print(f"计算结果: {result}")
结束嵌入
```

嵌入块中的代码直接共享段言变量作用域，无需显式传递。

## 第9步：进阶特性

### 链式方法调用

段言支持链式方法调用，可以像 Python 一样流畅地编写：

```段言
令 s = "Hello"
令 r = s.upper().lower()
打印 r  # 输出: hello

类 Calc:
    令 result = 0
    函数 add(self, n):
        self.result = self.result + n
        返回 self

令 c = Calc()
c.add(5).add(3)
打印 c.result  # 输出: 8
```

### 属性赋值

直接对对象属性赋值，支持链式属性访问：

```段言
类 Box:
    令 val = 0

令 b = Box()
b.val = 42
打印 b.val  # 输出: 42
```

### 模式匹配

段言原生支持 match-case 模式匹配：

```段言
函数 描述状态(状态码):
    匹配 状态码:
        情况 200:
            打印 "成功"
        情况 404:
            打印 "未找到"
        情况 _:
            打印 "未知状态"
```

### 异步编程

段言支持完整的异步语法：

```段言
异步 函数 获取数据(网址):
    令 响应 = 等待 请求(网址)
    返回 响应

异步 遍历 项 在 异步迭代器:
    打印 项
```
