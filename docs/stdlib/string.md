# 字符串处理模块

## 函数列表

| 函数 | 说明 |
|------|------|
| `长度(s)` | 获取字符串长度 |
| `子串(s, start, end)` | 截取子串 |
| `分割(s, sep)` | 分割字符串 |
| `拼接(列表, sep)` | 拼接字符串列表 |
| `替换(s, old, new)` | 替换子串 |
| `大写(s)` | 转换为大写 |
| `小写(s)` | 转换为小写 |
| `去空格(s)` | 去除首尾空格 |
| `包含(s, sub)` | 是否包含子串 |
| `开头(s, prefix)` | 是否以...开头 |
| `结尾(s, suffix)` | 是否以...结尾 |
| `格式化(fmt, ...)` | 格式化字符串 |
