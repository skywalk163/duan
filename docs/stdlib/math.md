# 数学模块

## 函数列表

| 函数 | 说明 |
|------|------|
| `sin(x)` | 正弦 |
| `cos(x)` | 余弦 |
| `sqrt(x)` | 平方根 |
| `log(x)` | 自然对数 |
| `log10(x)` | 常用对数 |
| `abs(x)` | 绝对值 |
| `floor(x)` | 向下取整 |
| `ceil(x)` | 向上取整 |
| `round(x)` | 四舍五入 |
| `max(a, b)` | 最大值 |
| `min(a, b)` | 最小值 |
| `pow(a, b)` | 幂运算 |
