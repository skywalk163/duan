# 日期时间模块

## 函数列表

| 函数 | 说明 |
|------|------|
| `现在()` | 获取当前时间 |
| `日期(年, 月, 日)` | 创建日期对象 |
| `时间(时, 分, 秒)` | 创建时间对象 |
| `格式化(dt, fmt)` | 格式化日期时间 |
| `解析(str, fmt)` | 解析日期字符串 |
| `时间戳()` | 获取当前时间戳 |
| `增量(dt, days=0, hours=0)` | 日期时间加减 |

## 格式说明

| 格式符 | 说明 |
|--------|------|
| `%Y` | 四位年份 |
| `%m` | 两位月份 |
| `%d` | 两位日期 |
| `%H` | 24小时制 |
| `%M` | 分钟 |
| `%S` | 秒 |

## 示例

```python
设 现在时间 = 现在()
印(格式化(现在时间, "%Y-%m-%d %H:%M:%S"))

# 日期计算
设 明天 = 增量(现在时间, days=1)
印(格式化(明天, "%Y-%m-%d"))
```
