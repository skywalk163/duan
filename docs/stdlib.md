# 标准库

段言提供丰富的中文标准库，位于 `stdlib/` 目录，包含 **12个阶段**、**50+个模块**。每个模块都有 Python 版本（.py）和段言版本（.duan）。

## 阶段1：基础核心模块

### builtins
