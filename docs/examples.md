## 变量和函数

```段言
函数 加法(甲, 乙):
    返回 甲 + 乙

函数 阶乘(n):
    如果 n <= 1:
        返回 1
    否则:
        返回 n * 阶乘(n - 1)

令 结果 = 加法(10, 20)
打印 结果
```

# 遍历列表
遍历 项 于 列表：
    打印 项

## 条件判断

```段言
令 年龄 = 20

如果 年龄 > 18:
    打印 "成年人"
否则：
    打印 "未成年人"
```

## 循环

```段言
# 当循环
令 计数 = 0
当 计数 < 5：
    打印 计数
    令 计数 = 计数 + 1

# 遍历循环
遍历 i 于 1至10：
    如果 i % 2 == 0:
        打印 i
```
