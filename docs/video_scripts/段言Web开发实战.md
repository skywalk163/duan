## 第2幕：数据模型（1:20 - 2:30）

**画面：** 编写 模型.duan

```段言
# 模型.duan - 博客数据模型

类 博客：
    属性 标题, 内容, 作者, 时间

    构造 接收 标题, 内容, 作者：
        己.标题 为 标题
        己.内容 为 内容
        己.作者 为 作者
        己.时间 为 当前时间()

    段落 摘要 接收 字数 = 50：
        返回 己.内容[:字数] + "..."

导出 博客
```

**旁白：**
"首先定义博客数据模型。用类来定义博客，包含标题、内容、作者和时间四个属性。构造方法接收参数并赋值。"

**代码高亮：** 逐行解释

**旁白：**
"己.标题 为 标题——这里的'己'相当于其他语言的 self 或 this。摘要方法返回文章的前 N 个字。"

## 第3幕：路由与服务（2:30 - 4:00）

**画面：** 编写 路由.duan

```段言
# 路由.duan - HTTP 路由配置

从 贡献.HTTP服务端 导入 路由, 响应, 请求
从 JSON 导入 序列化JSON

段落 配置路由 接收：
    设 路由表 为 路由()

    路由表.添加("GET", "/", 首页)
    路由表.添加("GET", "/文章/{id}", 文章详情)
    路由表.添加("POST", "/文章", 创建文章)
    路由表.添加("GET", "/api/文章", API文章列表)
    路由表.添加("POST", "/api/文章", API创建文章)

    返回 路由表

导出 配置路由
```

**旁白：**
"路由模块配置 HTTP 路径和处理函数的映射。支持 GET 和 POST 方法，以及路径参数——比如 /文章/{id}。"

**画面：** 展示路由处理函数

```段言
段落 首页 接收 请求：
    返回 渲染页面("index", {"标题": "我的博客", "文章": 文章列表})

段落 文章详情 接收 请求：
    设 id 为 转整数(请求.参数["id"])
    返回 渲染页面("detail", {"文章": 文章列表[id]})
```

**旁白：**
"每个路由绑定一个处理函数。首页返回文章列表，文章详情根据 ID 查找并返回单篇文章。"

## 第4幕：主程序（4:00 - 5:30）

**画面：** 编写 主.duan

```段言
# 主.duan - 博客系统入口

从 贡献.HTTP服务端 导入 创建服务器
从 路由 导入 配置路由
从 模型 导入 博客
从 JSON 导入 序列化JSON

# 内存数据存储
设 文章列表 为 []
设 下一个ID 为 0

段落 创建文章 接收 标题, 内容, 作者：
    设 新文章 为 博客(标题, 内容, 作者)
    文章列表.追加({"id": 下一个ID, "文章": 新文章})
    设 下一个ID 为 下一个ID + 1
    打印(f"创建文章：{标题}")

# 添加示例数据
创建文章("段言入门指南", "段言是一门中文编程语言……", "管理员")
创建文章("Web 开发实战", "用段言开发 Web 应用……", "管理员")

段落 主程序 接收：
    设 路由表 为 配置路由()
    设 服务器 为 创建服务器("0.0.0.0", 3000, 路由表)
    打印 "博客系统已启动：http://localhost:3000"
    服务器.启动()

主程序()
```

**旁白：**
"主程序整合所有模块。创建内存数据存储，添加示例数据，然后启动 HTTP 服务器监听 3000 端口。"

**画面：** 终端运行

```bash
duan run 主.duan
```

**输出：**
```
创建文章：段言入门指南
创建文章：Web 开发实战
博客系统已启动：http://localhost:3000
```

**旁白：**
"运行 duan run 主.duan，服务器启动。打开浏览器访问 http://localhost:3000。"
