# Playground 使用指南

## 启动

```bash
cd playground
python server.py
```

访问 `http://localhost:5000`

## 功能

- **代码编辑器**：基于 Monaco Editor，支持语法高亮
- **代码运行**：点击"运行"或 `Ctrl+Enter`
- **示例库**：内置 70+ 示例代码
- **交互式教程**：6 章 20 节教程
- **语法速查**：快速查看关键字和语法
- **标准库参考**：查看标准库文档
- **代码分享**：生成分享链接
- **项目管理**：多文件项目支持
- **主题切换**：深色/浅色主题
- **字体缩放**：调整编辑器字体大小
- **文体切换**：L1 白话 / L2 文言

## 输出面板

- **运行结果**：代码执行输出
- **AST 分析**：解析树结构
- **Token 分析**：词法分析结果
- **Python 代码**：编译后的 Python 代码
- **LLVM IR**：LLVM 中间表示

## 调试器

支持断点调试、单步执行、变量查看。
