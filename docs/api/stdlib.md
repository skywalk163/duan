## 数学模块

导入方式：`从 数学 导入 函数名` 或 `导入 数学`

### 三角函数

| 函数 | 说明 |
|------|------|
| `正弦(弧度)` | 正弦 |
| `余弦(弧度)` | 余弦 |
| `正切(弧度)` | 正切 |
| `反正弦(值)` | 反正弦 |
| `反余弦(值)` | 反余弦 |
| `反正切(值)` | 反正切 |

### 数学函数

| 函数 | 说明 |
|------|------|
| `平方根(数)` | 平方根 |
| `幂(底数, 指数)` | 幂运算 |
| `指数(数)` | e 的指数 |
| `对数(数[, 底数])` | 对数 |
| `阶乘(n)` | 阶乘 |
| `向上取整(数)` | 向上取整 |
| `向下取整(数)` | 向下取整 |
| `四舍五入(数[, 位数])` | 四舍五入 |

### 常量

| 常量 | 值 |
|------|-----|
| `π` | 3.141592653589793 |
| `e` | 2.718281828459045 |
