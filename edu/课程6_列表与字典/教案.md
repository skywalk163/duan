# 课程6：列表与字典

## 教学目标
- 理解列表的概念和用途
- 掌握列表的创建、访问、修改、添加和删除
- 理解字典的概念和用途
- 掌握字典的创建、访问、修改和遍历

## 知识点

### 1. 列表（列）
列表是一种有序的集合，可以存放多个数据。
```
设 列表名 = [元素1, 元素2, 元素3]
```

### 2. 列表操作
- 访问元素：`列表[下标]`
- 添加元素：`列表的 添加 元素`
- 删除元素：`列表的 删除 元素`
- 弹出元素：`列表的 弹出`
- 排序：`列表的 排序`
- 反转：`列表的 反转`
- 长度：`列表的长度`

### 3. 字典（典）
字典是一种键值对存储结构，通过键来查找值。
```
设 字典名 = {"键1": 值1, "键2": 值2}
```

### 4. 字典操作
- 访问值：`字典["键"]`
- 修改值：`字典["键"] = 新值`
- 添加键值：`字典["新键"] = 新值`
- 遍历键：`遍 字典 的键 为 键`
- 遍历值：`遍 字典 的值 为 值`
- 遍历项：`遍 字典 的项 为 项`

## 课堂练习
1. 创建列表并添加删除元素
2. 遍历字典打印所有键值对
3. 统计列表中各元素出现次数

## 作业
1. 编写程序将两个列表合并并去重
2. 编写程序用字典统计学生成绩的平均分
