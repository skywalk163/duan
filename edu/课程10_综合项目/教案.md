# 课程10：综合项目——学生管理系统

## 教学目标
- 综合运用所学知识完成一个完整的项目
- 掌握项目设计和模块划分的方法
- 学会使用列表、字典、函数、文件操作等知识
- 培养编程解决问题的综合能力

## 知识点

### 1. 项目设计
- 需求分析：明确程序要做什么
- 功能设计：划分不同的功能模块
- 界面设计：设计用户交互方式

### 2. 功能模块
- 添加学生信息
- 查看所有学生
- 查询单个学生
- 修改学生信息
- 删除学生信息
- 保存数据到文件
- 从文件读取数据

### 3. 项目结构
```
主程序：
  1. 显示菜单
  2. 等待用户选择
  3. 执行对应功能
  4. 循环直到退出
```

## 课堂练习
1. 设计项目的功能列表
2. 实现添加和查看功能
3. 实现保存和读取功能

## 作业
1. 增加"按成绩排名"功能
2. 增加"统计班级信息"（总人数、平均分等）
