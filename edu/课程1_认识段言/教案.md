# 课程1：认识段言

## 教学目标
- 了解什么是编程语言
- 掌握段言的安装和运行
- 编写第一个段言程序

## 知识点

### 1. 什么是编程？
编程就是告诉计算机做什么。就像我们用中文和人交流，用段言和计算机交流。

### 2. 第一个程序
段言中最简单的程序就是让计算机"说话"：

```
打印 "你好，世界！"
```

### 3. 运行程序
```bash
python -m cli.duan run 文件名.duan
```

## 课堂练习
1. 打印你的名字
2. 打印一句问候语
3. 打印多行内容

## 作业
1. 编写程序打印一首诗
2. 尝试打印数字和文字的组合
