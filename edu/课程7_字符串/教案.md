# 课程7：字符串

## 教学目标
- 理解字符串的概念
- 掌握字符串的拼接、截取、查找和替换
- 学会格式化字符串
- 了解常用字符串方法

## 知识点

### 1. 字符串
字符串是用引号括起来的文本。
```
设 文本 = "你好，世界！"
```

### 2. 字符串操作
- 拼接：`字符串1 + 字符串2`
- 长度：`字符串的长度`
- 截取：`字符串[起始:结束]`
- 查找：`字符串的 查找 子串`
- 替换：`字符串的 替换 "旧" "新"`

### 3. 字符串格式化
- 使用 `串(数字)` 将数字转为字符串
- 使用 `+` 拼接变量和文本

### 4. 常用方法
- 转大写/小写
- 去除空白
- 分割字符串
- 判断开头/结尾

## 课堂练习
1. 字符串拼接和截取
2. 字符串查找和替换
3. 格式化输出个人信息

## 作业
1. 编写程序反转字符串
2. 编写程序判断字符串是否为回文
