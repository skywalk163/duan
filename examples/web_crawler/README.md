# Web 爬虫示例

演示如何使用段言标准库实现一个简单的 Web 爬虫，支持递归抓取链接并生成站点地图。

## 功能

- 接受起始 URL 作为输入
- 通过 HTTP 请求获取页面内容
- 使用正则表达式提取所有超链接（href 属性）
- 将相对 URL 转换为绝对 URL
- 过滤非 HTML 资源（图片、文档、音视频等）
- 限制在同一域名下抓取
- 可配置递归抓取深度
- 自动去重，避免重复抓取
- 输出结构化站点地图报告（文本 + JSON）
- 错误处理和超时控制

## 用法

```bash
# 基本用法 - 抓取单个页面
duan run examples/web_crawler/crawler.duan "https://example.com"

# 指定抓取深度 - 递归抓取 2 层
duan run examples/web_crawler/crawler.duan "https://example.com" 2

# 查看帮助信息
duan run examples/web_crawler/crawler.duan
```

## 参数说明

| 参数 | 必需 | 默认值 | 说明 |
|------|------|--------|------|
| `URL` | 是 | - | 起始抓取地址 |
| `深度` | 否 | `1` | 递归抓取的最大深度 |

## 输出

程序运行后会在当前目录生成以下输出：

1. **控制台输出** - 实时显示抓取进度和站点地图报告
2. **sitemap.json** - 结构化的站点地图 JSON 文件，包含每个页面的深度、链接数和子链接列表

## 涉及的语言特性

- `段落` 函数定义与参数传递
- `设` 变量声明
- `如果`/`否则若`/`否则` 条件判断
- `遍历` 列表遍历循环
- `当` 条件循环
- `尝试`/`捕获` 异常处理
- `导入` 标准库模块
- 字典和列表操作
- 字符串处理（正则表达式、分割、拼接、大小写转换）
- 文件读写（JSON 序列化）
- HTTP 网络请求
