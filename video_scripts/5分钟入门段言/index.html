    《5 分钟入门段言》视频脚本¶

    版本： v6.0 时长： 5 分钟 适用对象： 编程零基础用户

    片头（0:00 - 0:15）¶

    画面： 段言 Logo 动画 + 标题「5 分钟入门段言」

    旁白： "段言，一门用中文编程的语言。5 分钟，让你写出第一个程序。"

    第1幕：段言是什么（0:15 - 0:50）¶

    画面： 对比展示 Python 代码和段言代码

    # Python
name = "张三"
age = 25
print(name)

# 段言
设 姓名 为 "张三"
设 年龄 为 25
打印 姓名

    旁白： "段言是一门中文编程语言。所有关键字都是中文——设变量、打印输出、如果判断条件。你不需要懂英语，就能写代码。"

    画面： 展示特性列表动画 - 中文关键字 - 标准库丰富 - 支持 LLVM 原生编译 - 内置 AI 辅助

    旁白： "它内置了 60 多个标准库模块，支持 LLVM 原生编译，还有 AI 辅助工具。但今天，我们只做一件事——安装并运行第一个程序。"

    第2幕：安装段言（0:50 - 1:30）¶

    画面： 终端录屏，逐行输入命令

    pip install duan

    旁白： "安装段言只需要一条命令：pip install duan。前提是你的电脑上安装了 Python 3.10 或更高版本。"

    画面： 验证安装

    duan --version

    旁白： "安装完成后，输入 duan --version 验证。看到版本号，就说明安装成功了。"

    第3幕：第一个程序（1:30 - 2:30）¶

    画面： 创建 hello.duan 文件

    # hello.duan
打印 "你好，段言！"

    旁白： "创建一个文件，叫 hello.duan，里面写一行：打印 '你好，段言！'"

    画面： 运行程序

    duan run hello.duan

    输出： 

    你好，段言！

    旁白： "打开终端，输入 duan run hello.duan。终端输出了'你好，段言！'——恭喜，你写出了第一个段言程序！"

    第4幕：基础语法（2:30 - 3:30）¶

    画面： 展示变量、条件、循环代码

    # 变量
设 名字 为 "小明"
设 年龄 为 18

# 条件
如果 年龄 >= 18：
    打印 "成年"
否则：
    打印 "未成年"

# 循环
遍历 i 在 1 到 5：
    打印 i

    旁白： "接下来看看基础语法。设 变量 为 值——声明变量。如果 条件：——做判断。遍历 项 在 范围：——循环。这些关键字都是中文，非常直观。"

    画面： 代码逐行高亮，解释每个关键字

    旁白： "你不需要记住任何英文单词。段言的设计目标就是让中文使用者零门槛上手编程。"

    第5幕：函数与模块（3:30 - 4:20）¶

    画面： 展示函数和模块导入

    # 定义函数
段落 加法 接收 a, b：
    返回 a + b

# 导入模块
导入 数学
设 结果 为 数学.平方根(16)
打印 结果  # 输出：4.0

    旁白： "用'段落'定义函数，用'返回'返回结果。用'导入'加载标准库——数学模块提供平方根、三角函数等常用函数。"

    画面： 展示更多标准库模块

    旁白： "段言内置了 60 多个模块：文件操作、JSON 解析、HTTP 请求、加密……你想要的，基本都有。"

    第6幕：下一步与总结（4:20 - 5:00）¶

    画面： 展示更多资源

    duan tutorial          # 交互式教程
duan repl              # 交互式环境
duan ai "写一个排序"   # AI 生成代码

    旁白： "5 分钟到了，但你还能做更多。运行 duan tutorial 开始交互式教程，或者 duan repl 进入交互式编程环境。甚至可以用 AI 帮你写代码——duan ai '写一个排序算法'。"

    画面： 段言 Logo + 网址 + 二维码

    旁白： "段言，让中文编程更简单。访问官网了解更多。我们下个视频见！"

    技术说明¶

    • 视频分辨率： 1920×1080
    • 帧率： 30fps
    • 配色方案： 段言品牌色（蓝色 #2563EB、白色 #FFFFFF）
    • 代码字体： JetBrains Mono 或等宽字体
    • 背景音乐： 轻快、无版权音乐
    • 字幕： 中文简体 + 英文字幕（可选）
