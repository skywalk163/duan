    30 分钟入门段言¶

    段言是一门中文编程语言——关键字用中文书写，同时支持中文运算符和符号运算符，让零基础用户也能快速上手编程。

    本教程专为从未写过代码的中文用户设计，跟着读完即可独立编写简单程序。

    1. 环境准备¶

    1.1 安装 Python¶

    段言运行在 Python 之上，所以第一步是安装 Python（3.10 或更高版本）。

    去 python.org 下载安装包，运行时勾选 Add Python to PATH，一路「下一步」即可。

    安装完成后，打开终端（Windows 按 Win+R，输入 cmd 回车），输入：

    python --version

    看到类似 Python 3.12.x 的输出就说明安装成功。

    1.2 安装段言¶

    在终端中执行：

    pip install duan

    1.3 验证安装¶

    duan --version

    看到 段言编译器 v1.x.x 说明安装成功。

    现在创建一个测试文件 hello.duan，写入以下内容：

    打印 "你好，段言！"

    然后运行：

    duan run hello.duan

    如果终端输出 你好，段言！，恭喜你——环境搭建完毕！

    小结¶

    命令 作用
    pip install duan 安装段言
    duan --version 查看版本
    duan run 文件名.duan 运行段言程序

    2. 第一个程序¶

    2.1 打印¶

    打印 是段言最常用的命令，作用是把内容显示到屏幕上：

    打印 "你好，世界！"

    你也可以用括号写法，效果一样：

    打印("你好，世界！")

    2.2 变量¶

    变量就像一个「盒子」，可以存放数据。段言使用 设 关键字声明变量：

    设 名字 为 "张三"
设 年龄 为 25

打印 名字
打印 年龄
    • 设 表示「我要创建一个变量」
    • 名字 是变量名（你可以自己起名）
    • 为 把右边的值放进左边

    句号说明：段言语句末尾的句号「。」是可选的——加了不影响运行，不加也完全没问题。本教程的示例一律不加句号，保持简洁。

    2.3 f-string 字符串插值¶

    在字符串前面加 f，就可以用 {} 把变量嵌入文字中：

    设 名字 为 "段言"
设 版本 为 1.11

打印(f"语言：{名字}，版本：{版本}")

    输出：

    语言：段言，版本：1.11

    2.4 注释¶

    以 # 开头的行是注释，程序执行时会跳过它。注释是给人看的说明文字：

    # 这是一行注释
设 甲 为 10  # 这也是注释
打印 甲

    小结¶

    语法 作用 示例
    打印 输出到屏幕 打印 "你好"
    设 X 为 Y 创建变量 设 年龄 为 25
    f"..." 字符串插值 f"我叫{名字}"
    # 注释 # 说明文字

    3. 基本运算¶

    3.1 算术运算¶

    段言同时支持符号运算符和中文运算符，两者完全等价。推荐使用符号写法（更简洁）：

    设 甲 为 10
设 乙 为 3

打印(甲 + 乙)       # 加法 → 13    等价于：甲 加 乙
打印(甲 - 乙)       # 减法 → 7     等价于：甲 减 乙
打印(甲 * 乙)       # 乘法 → 30    等价于：甲 乘 乙
打印(甲 / 乙)       # 除法 → 3.333...  等价于：甲 除 乙
打印(甲 // 乙)      # 整除 → 3     等价于：甲 整除 乙
打印(甲 % 乙)       # 取余 → 1     等价于：甲 取余 乙
打印(甲 ** 乙)      # 幂运算 → 1000    等价于：甲 幂 乙

    提示：段言也支持 print 写法，与 打印 完全等价。+ 还可以用于字符串拼接："你好" + "世界"。

    也支持中文数字字面量：

    设 结果 为 三 + 五
打印 结果    # 输出: 8

    3.2 比较运算¶

    比较运算的结果是 真（成立）或 假（不成立）。符号和中文写法均可：

    设 甲 为 10
设 乙 为 5

打印(甲 > 乙)        # 真    等价于：甲 大于 乙
打印(甲 < 乙)        # 假    等价于：甲 小于 乙
打印(甲 == 乙)       # 假    等价于：甲 等于 乙
打印(甲 != 乙)       # 真    等价于：甲 不等于 乙
打印(甲 >= 乙)       # 真    等价于：甲 大于等于 乙

    3.3 逻辑运算¶

    在 如果 条件中，可以用 且（两个都满足）、或（满足其一即可）连接多个条件：

    设 甲 为 10
设 乙 为 5
设 丙 为 3

如果 甲 > 乙 且 乙 > 丙：
    打印 "甲>乙>丙，条件链成立"

    非 表示「取反」：

    设 开关 为 假
如果 非 开关：
    打印 "开关是关闭的"

    3.4 运算简写¶

    修改变量自身时，直接用 = 重新赋值即可：

    设 计数 为 0
计数 = 计数 + 1    # 计数变成 1
计数 = 计数 + 1    # 计数变成 2
打印 计数           # 输出: 2

    也可以用中文复合赋值：

    设 计数 为 0
计数 加上 1    # 等价于 计数 = 计数 + 1
打印 计数       # 输出: 1

    小结¶

    运算 符号写法 中文写法 示例（符号）
    加 + 加 / 加上 甲 + 乙
    减 - 减 / 减去 甲 - 乙
    乘 * 乘 / 乘以 甲 * 乙
    除 / 除 / 除以 甲 / 乙
    整除 // 整除 甲 // 乙
    取余 % 取余 / 模 甲 % 乙
    幂 ** 幂 / 幂以 甲 ** 乙
    大于 > 大于 甲 > 乙
    小于 < 小于 甲 < 乙
    等于 == 等于 甲 == 乙
    不等于 != 不等于 甲 != 乙
    大于等于 >= 大于等于 甲 >= 乙
    小于等于 <= 小于等于 甲 <= 乙
    且 — 且 / 与 条件1 且 条件2
    或 — 或 条件1 或 条件2
    非 — 非 非 开关

    提示：符号写法和中文写法可以混用，如 甲 + 乙 大于 10 完全合法。

    4. 条件判断¶

    4.1 如果...否则¶

    条件判断让程序「看情况办事」：

    设 分数 为 85

如果 分数 >= 60：
    打印 "及格"
否则：
    打印 "不及格"

    4.2 多条件：否则如果¶

    设 分数 为 85

如果 分数 >= 90：
    打印 "优秀"
否则如果 分数 >= 60：
    打印 "及格"
否则：
    打印 "不及格"

    程序从上往下检查，一旦某个条件满足就执行对应代码块，不再往下检查。

    4.3 嵌套条件¶

    条件里面可以再嵌套条件：

    设 甲 为 10
设 乙 为 20

如果 甲 > 5：
    如果 乙 > 15：
        打印 "两个条件都满足"
    否则：
        打印 "只有甲满足"
否则：
    打印 "都不满足"

    4.4 三元表达式¶

    简单二选一可以用一行写完：

    设 数 为 10
设 结果 为 "偶数" 如果 数 % 2 == 0 否则 "奇数"
打印 结果    # 输出: 偶数

    读法：结果 等于 "偶数"，如果 条件成立；否则 等于 "奇数"。

    小结¶

    语法 作用
    如果 条件： 条件成立时执行
    否则如果 条件： 上一个条件不满足时再判断
    否则： 所有条件都不满足时执行
    值 如果 条件 否则 值 一行二选一

    注意：条件行末尾的冒号 ： 不能省略，代码块必须缩进（每层缩进 4 个空格或 1 个 Tab，保持一致即可）。

    5. 循环¶

    循环让程序重复执行一段代码，不用手动复制粘贴。

    5.1 当循环（while）¶

    当 相当于「只要条件成立，就一直做」：

    设 计数 为 1
当 计数 <= 5：
    打印(f"第{计数}次")
    计数 = 计数 + 1

    输出：

    第1次
第2次
第3次
第4次
第5次

    重要：别忘了在循环体内更新计数变量，否则会变成无限循环！

    5.2 遍历循环（for）¶

    遍历 用于依次取出列表或范围中的每个元素：

    遍历 项 从 1 到 5：
    打印 项

    输出 1 到 5，每个数字一行。

    从 1 到 5 表示从 1 到 5（含 5）。也可以指定步长：

    遍历 项 从 1 到 10 步 2：
    打印 项

    输出：1 3 5 7 9（每次跳 2）。

    也可以遍历列表：

    设 颜色 为 ["红", "绿", "蓝"]
遍历 颜色 为 色：
    打印 色

    5.3 跳出和跳过¶

    • 跳出：立刻结束整个循环（相当于 break）
    • 跳过：跳过当前这一轮，直接进入下一轮（相当于 continue）
    遍历 项 从 1 到 10：
    如果 项 % 2 == 0：
        跳过
    打印 项

    输出：1 3 5 7 9（只打印奇数，偶数被跳过）。

    遍历 项 从 1 到 10：
    如果 项 > 5：
        跳出
    打印 项

    输出：1 2 3 4 5（到 6 时跳出循环，不再执行）。

    小结¶

    语法 作用 示例
    当 条件： 条件成立就重复 当 计数 小于 10：
    遍历 X 从 开始 到 结束： 依次遍历范围 遍历 i 从 1 到 5：
    遍历 列表 为 X： 遍历列表 遍历 水果 为 项：
    从 A 到 B 范围 A 到 B 从 1 到 10
    从 A 到 B 步 C 范围带步长 从 1 到 10 步 2
    跳出 结束循环 跳出
    跳过 跳过本轮 跳过

    6. 段落（函数）¶

    「段落」就是一段可以反复使用的代码。你把一段逻辑写成段落，以后调用它就行，不用重复写。

    6.1 定义和调用¶

    段言使用 段落 关键字定义函数：

    段落 问好 接收 名字:
    打印(f"你好，{名字}！")

问好("张三")
问好("李四")

    段落 问好 接收 名字:
    打印(f"你好，{名字}！")

问好("张三")

    本教程以 段落 语法为主。

    6.2 返回值¶

    函数可以把结果「返回」给调用者：

    段落 加法 接收 a, b:
    返回 a + b

设 结果 为 加法(3, 5)
打印 结果    # 输出: 8

    返回 表示「把后面的值交出去，函数到此结束」。

    6.3 递归¶

    函数可以调用自己，这叫递归。经典例子是阶乘：

    段落 阶乘 接收 n:
    如果 n <= 1：
        返回 1
    返回 n * 阶乘(n - 1)

打印 阶乘(5)    # 输出: 120

    执行过程：阶乘(5) → 5 * 阶乘(4) → 5 * 4 * 阶乘(3) → ... → 5 * 4 * 3 * 2 * 1 = 120。

    6.4 多参数¶

    段落 创建名片 接收 姓名, 职业:
    返回 f"{姓名} - {职业}"

打印 创建名片("张三", "工程师")

    小结¶

    语法 作用 示例
    段落 名 接收 参数: 定义函数 段落 加法 接收 a, b:

    | 返回 值 | 返回结果 | 返回 a + b | | 名(参数) | 调用函数 | 加法(3, 5) |

    7. 列表与字符串¶

    7.1 列表¶

    列表用于存储一组有序的数据：

    设 水果 为 ["苹果", "香蕉", "橘子"]
打印 水果

    访问元素（从 0 开始计数）：

    设 水果 为 ["苹果", "香蕉", "橘子"]
打印 水果[0]    # 输出: 苹果
打印 水果[1]    # 输出: 香蕉

    添加元素：

    设 水果 为 ["苹果", "香蕉"]
水果.追加("橘子")
打印 水果    # 输出: ['苹果', '香蕉', '橘子']

    列表长度：

    设 水果 为 ["苹果", "香蕉", "橘子"]
打印(长度(水果))    # 输出: 3

    列表排序：

    设 数字 为 [3, 1, 4, 1, 5, 9, 2, 6]
数字.排序()
打印 数字    # 输出: [1, 1, 2, 3, 4, 5, 6, 9]

    7.2 字符串¶

    字符串就是一段文字，用引号包裹：

    设 名字 为 "段言"

    拼接：

    设 问候 为 "你好，"
设 对象 为 "世界"
打印(问候 + 对象)    # 输出: 你好，世界

    长度：

    设 名字 为 "段言"
打印(长度(名字))    # 输出: 2

    访问字符：

    设 名字 为 "段言"
打印 名字[0]    # 输出: 段

    转换大小写：

    设 英文 为 "hello"
打印(转大写(英文))    # 输出: HELLO
打印(转小写(英文))    # 输出: hello

    7.3 列表推导¶

    列表推导是一种用一行代码生成列表的简洁写法：

    设 平方数 为 [x * x 遍历 x 之 范围(1, 6)]
打印 平方数    # 输出: [1, 4, 9, 16, 25]

    读法：x * x（每个元素的值），遍历 x 之 范围(1, 6)（x 从 1 到 5）。

    带条件筛选：

    设 偶数 为 [x 遍历 x 之 范围(1, 11) 若 x % 2 == 0]
打印 偶数    # 输出: [2, 4, 6, 8, 10]

    7.4 字典¶

    字典用于存储键值对：

    设 学生 为 {"名字": "张三", "年龄": 25}
打印 学生["名字"]    # 输出: 张三
打印 学生["年龄"]    # 输出: 25

    添加新的键值对：

    设 学生 为 {"名字": "张三"}
学生["年龄"] = 25
打印 学生    # 输出: {'名字': '张三', '年龄': 25}

    遍历字典：

    设 学生 为 {"名字": "张三", "年龄": 25, "城市": "北京"}
遍历 学生 为 键：
    打印(f"{键}: {学生[键]}")

    小结¶

    操作 语法 示例
    创建列表 [元素, 元素] [1, 2, 3]
    访问元素 列表[索引] 水果[0]
    添加元素 列表.追加(元素) 水果.追加("橘子")
    列表长度 长度(列表) 长度(水果)
    字符串拼接 字符串 + 字符串 "a" + "b"
    列表推导 [表达式 遍历 变量 之 范围] [x * x 遍历 x 之 范围(1, 6)]
    字典 {"键": "值"} {"名字": "张三"}

    8. 类与对象¶

    8.1 什么是类¶

    「类」就像一个模具——你设计好模具，就能用它批量生产「对象」。

    比如「动物」是一个类，具体的「小狗旺财」就是一个对象。

    8.2 定义类并创建对象¶

    类 动物：
    属性 名字

    构造 接收 名字：
        己.名字 为 名字

    段落 介绍 接收:
        打印(f"我叫{己.名字}")

设 小狗 为 动物("旺财")
小狗.介绍()
    - 类 动物： — 定义一个叫 动物 的类 - 属性 名字 — 声明这个类有一个属性叫 名字 - 构造 接收 名字： — 创建对象时接收名字参数 - 己.名字 为 名字 — 把参数赋值给对象自己的属性（己 相当于 Python 的 self） - 段落 介绍 接收: — 定义一个方法 - 设 小狗 为 动物("旺财") — 创建一个 动物 对象，起名叫旺财 - 小狗.介绍() — 调用对象的方法

    9.1 猜数字游戏¶

    程序预设一个数字，玩家猜大猜小都有提示，直到猜对为止。

    为了演示方便，我们用固定值代替随机数。你也可以通过设置不同的猜测来体会逻辑：

    设 目标 为 7
设 猜测 为 0
设 次数 为 0

当 猜测 != 目标：
    次数 = 次数 + 1

    如果 次数 == 1：
        猜测 = 3
    否则如果 次数 == 2：
        猜测 = 5
    否则：
        猜测 = 7

    如果 猜测 > 目标：
        打印(f"第{次数}次：猜了{猜测}，太大了！")
    否则如果 猜测 < 目标：
        打印(f"第{次数}次：猜了{猜测}，太小了！")
    否则：
        打印(f"第{次数}次：猜了{猜测}，猜对了！")

打印(f"总共猜了{次数}次")

    输出：

    第1次：猜了3，太小了！
第2次：猜了5，太小了！
第3次：猜了7，猜对了！
总共猜了3次
