段言 v4.0

中文编程语言 · 五层分层架构 · 像中文一样设计

段言 v4.0 借鉴中文"字→文体→领域→外语"的分层智慧，用 30 个核心字驱动从教学到商业的全场景编程。

简介

段言（Duan）是一门中文编程语言。v4.0 的核心设计理念是像中文一样分层：

  • 字（L0 核心字）极少且稳定 —— 仅 30 字
  • 文体（L1 白话 / L2 文言）分层但不分裂，共享字
  • 领域（L3 SQL / 正则 / 数学）直接吸收，不翻译
  • 外语（L4 Python / C / Go / MoonBit）用 引 块引用

快速开始

# 安装
pip install duan4

# 运行
duan hello.duan

# 或直接使用 Python
python -c "from duan_parser_v3 import DuanParser; ..."

L3 领域嵌入

L3 直接在段言代码中嵌入 SQL、正则表达式、数学公式，无需特殊标记：

# SQL 嵌入
设 DB = ":memory:"
l3_sql_exec(DB, "CREATE TABLE t (id INTEGER, name TEXT)")
设 结果 = l3_sql_query(DB, "SELECT * FROM t")

# 正则嵌入
设 邮箱正则 = "[a-zA-Z]+@[a-zA-Z]+\\.[a-zA-Z]+"
l3_re_match(邮箱正则, "test@duan-lang.org")

# 数学嵌入
l3_math_solve_quadratic(2, 5, -3)  # 解方程 2x²+5x-3=0

L4 外语引用

通过 引 语言: 块嵌入 Python、C、Go、MoonBit 代码，运行在隔离沙箱中：

# Python 引用
引 Python:
    import numpy as np
    def l4_numpy_mean(arr):
        return float(np.mean(arr))
结束引

设 数据 = 列(1, 2, 3, 4, 5)
印(l4_numpy_mean(数据))  # 3.0

v3.3 → v4.0 迁移

v4.0 完全兼容 v3.3 代码。所有 v3.3 双字关键字作为别名永久保留：

# v3.3 风格（仍然有效）
如果 甲 大于 乙：
  打印("甲更大")

# v4.0 风格（推荐）
若 甲 > 乙：
  印("甲更大")

详见 v3.3→v4.0 迁移指南
